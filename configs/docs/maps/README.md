# Retained native report publication

`report-owner.json` declares the exact original atlas documents, their local
assets and data registrations, the Swedish sequence chart and its six local data
files, and the passive Sweden lake availability notice. `mkdocs.yml` explicitly
selects this descriptor. The publication renderer must receive the same selector
and source revision during rendering and mechanical admission.

`report-readers.json` gives each original report a purpose, a documentation return
route and a search route. The descriptor also binds the sole Nordic documentation
iframe to its original Markdown and rendered parent page.

Publication qualification preserves the original reports and scientific inputs.
It verifies presentation source, resource ownership, executable recipes, navigation
and browser policy. It does not recompute or certify scientific results. The
historical Nordic document is 526299 bytes, 2011 bytes beyond the 524288-byte value
recorded in its original bootstrap. The shared standard admits only that exact
reviewed document and producer closure; unrelated documents retain the default
limit. This does not correct the historical bootstrap claim.

The Swedish chart has no inert bootstrap. Its independently reviewed original
script reads exactly three same-origin files and displays retained sample and
native-taxon rows. Its complete six-file data closure includes the original source
manifest and downloadable tables. This capability does not permit arbitrary JSON
resources or bootstrap-free scripts.

Street and Terrain tiles remain the two original external providers. Their
activation, attribution and privacy behavior are declared per report. Selecting
No basemap leaves the local evidence controls usable without tiles.

When an original report, producer, configuration or resource intentionally changes,
review the affected ownership records and shared native profile together before
publication. Do not modify original outputs merely to satisfy their previous
identities. Capture the actual parent page identity with the frozen publication
renderer after a change that affects its HTML.
