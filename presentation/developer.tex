\begin{frame}{Begin with one source-to-result responsibility}
\begin{center}
Source bytes $\rightarrow$ custody $\rightarrow$ normalized record $\rightarrow$ admission\\[0.8em]
$\rightarrow$ calculation or frozen prediction $\rightarrow$ score $\rightarrow$ reader report
\end{center}
\begin{itemize}
\item Identify the owner of the boundary you are changing and its actual consumer.
\item Bind physical site, ages, taxon denominator, geometry and permitted use separately.
\item Preserve failed and refused rows alongside successful results.
\end{itemize}
\scope{A format or build check proves its declared contract. A new scientific claim also needs admissible data and qualified review.}
\evidence{reports/architecture/ownership.md; reports/science/source-cohorts.md}
\end{frame}

\begin{frame}[fragile]{Use the locked repository environment for development}
\small
From the repository root, use the existing governed environment route:
\begin{verbatim}
UV_CACHE_DIR=artifacts/root/cache/uv \
  uv sync --locked --group dev
.venv/bin/bijux-pollenomics run-lra --help
\end{verbatim}
The development group includes the host, optional engine and maintainer tools.
The report extra declares its Markdown parser. PDF exports additionally need
XeLaTeX, latexmk, Graphviz and the named fonts in the renderer instructions.
\scope{A previous clean built-wheel install ran R-free examples on this platform. The dated public-index check found no engine release; a public extra-install route remains unverified.}
\evidence{pyproject.toml; uv.lock; reports/architecture/lra-distribution.md}
\end{frame}

\begin{frame}{Tracked evidence and private source bytes serve different roles}
\begin{itemize}
\item Tracked source identities, derived ledgers and rights-safe report text identify the result being discussed.
\item Lawful original transports, restricted workbooks and article packets remain in the qualified source store; readers do not acquire reuse rights from a citation.
\item An immutable manifest binds source revision, bytes and declared selection. Synthetic fixtures retain their synthetic labels.
\item New inputs go through custody, schema and scientific admission before a historical LRA run.
\end{itemize}
\scope{Neither a modern lake centroid nor an alternative chronology proves the historical core/window/basin used in a publication.}
\evidence{reports/science/source-cohorts.md}
\end{frame}

\begin{frame}[fragile]{A bounded workflow: export one canonical paper account}
\small
This example requires no restricted raw source. The report and inventory must
match the committed revision. Choose an output directory that does not exist:
\begin{verbatim}
SOURCE_DATE_EPOCH=1790812800 PYTHONDONTWRITEBYTECODE=1 \
 .venv/bin/python -m bijux_pollenomics_dev.reader_reports \
 --repository . --inventory reports/science/paper-accounts.csv \
 --paper-id regional-reveals-theory \
 --output artifacts/jobs/contributor-paper-example
\end{verbatim}
Read the PDF beside its receipt: canonical text, citation links, source/producer
hashes and compiler logs. Inspect every page before retaining an export.
\scope{This is a report workflow, not a new reconstruction or independent scientific confirmation.}
\evidence{reports/exports/papers/README.md; packages/bijux-pollenomics-dev/src/bijux_pollenomics_dev/reader_reports/README.md}
\end{frame}

\begin{frame}{LRA requests use the host's explicit admission contract}
\begin{itemize}
\item \texttt{validate-lra-input} checks the typed request and its source evidence. \texttt{run-lra} creates an exploratory bundle in a new directory.
\item A request declares count units, taxa, parameters, physical basin/rings, age support, evidence identities, exclusions and uncertainty omissions.
\item Missing/incompatible engines, invalid inputs and nonconvergence return structured refusals. Successful computation remains \texttt{generated\_exploratory}.
\end{itemize}
\scope{REVEALS estimates regional vegetation; LOVE estimates local vegetation using regional background. Pollen prediction, modeled cover and measured-vegetation accuracy need distinct targets.}
\evidence{docs/public/pollenomics/interfaces/cli-surface.md; docs/public/pollenomics/architecture/lra-engine.md}
\end{frame}

\begin{frame}{A new source or producer needs a real input closure}
\begin{enumerate}
\item Add custody and permitted-use evidence under the owning source family. Validate source schema, identities, population and explicit refusals.
\item Keep training inputs separate from target outcomes; freeze predictions before scoring. Physical-site grouping and prior exposure remain visible.
\item A producer reads authenticated parents, writes only its owned paths and accounts for every attempted/refused unit.
\item Link its result, manifest, reproduction command and limitation from the canonical report and affected public consumer.
\end{enumerate}
\scope{Do not generate a matching output by copying the tracked result into its supposed independent input.}
\evidence{reports/architecture/ownership.md; reports/science/pollen-prediction.md}
\end{frame}

\begin{frame}[fragile]{Select checks from the boundary that changed}
\small
For report text and PDF identity, begin with:
\begin{verbatim}
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python reports/verify.py
.venv/bin/python docs/report/pollen-reconstruction/verify_report.py
.venv/bin/python presentation/build.py
\end{verbatim}
Source data needs rights/schema/count/admission checks; numerical code needs
its affected oracle, failure and uncertainty cases. A changed public route
needs the strict site build and its actual browser/export consumer. A package
change needs its installed wheel/metadata boundary.
\scope{Use existing unchanged receipts only within their input scope. The final stable release candidate still needs its complete integration matrix.}
\evidence{reports/verify.py; docs/report/pollen-reconstruction/verify_report.py; presentation/build.py}
\end{frame}

\begin{frame}{Diagnose a refusal at its owning boundary}
\begin{itemize}
\item \textbf{Source lock changed:} review the changed claim/source; rebuild the affected export before accepting its new identity.
\item \textbf{Compiler timeout:} inspect the retained log; correct the source or tool/font environment and rerun into an isolated directory.
\item \textbf{Unsupported scientific input:} name the missing core/age/basin/count/parameter/rights field and request its authority.
\item \textbf{Failed numerical fit:} retain diagnostic and coverage rows; do not convert the failure to a zero score.
\end{itemize}
\scope{Human reading, source decisions and qualified scientific review remain explicit inputs; model review does not supply them.}
\evidence{reports/science/model-use.md; presentation/README.md}
\end{frame}
