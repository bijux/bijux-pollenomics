# Read the scientific accounts offline

Download a paper account or an audience briefing, then open it in a PDF reader.
Each file includes its explanation, evidence references and limitations. The
website build serves the same reviewed bytes as the repository's retained
exports. It does not require access to private source data to open these files.

The accounts distinguish published findings, our numerical reproduction,
development pollen predictions and independent vegetation accuracy. Current
Nordic predictions have no admitted matched vegetation reference; their pollen
scores do not measure vegetation accuracy. Read [papers and evidence roles](papers.md)
before interpreting a reconstruction or choosing a method.

## Use the downloaded files

Save a file before disconnecting; its main text, tables and diagrams remain
readable offline. Citation and repository evidence links require a connection.
The paper PDFs use commit-pinned evidence links whose public availability has
not been verified for this local candidate. Follow [results and model use](results.md)
for current scope, or the repository's
source requests
for the exact missing data and reviewer decisions. A missing measurement is not
a zero accuracy score.
