# Scientific evidence

The repository now has source-bound results for Nordic observed-pollen
prediction, selected author method correspondence, and an English LRA
reconstruction with forward-pollen predictions. Each supports a different
claim. A calculation matching published author code says how faithfully a
method was implemented; a withheld pollen score says how it predicts pollen
on its tested sites; neither measures vegetation accuracy.

The public pages summarize governed tables without distributing private raw
sources. Exact rows, producer commands and limitations are linked from each
page. The repository's [claim-to-evidence index](https://github.com/bijux/bijux-pollenomics/blob/main/reports/evidence-index.md)
connects headline findings to numeric tables, manifests and producers. Open
source questions remain visible in the repository's
[`reports/needed` register](https://github.com/bijux/bijux-pollenomics/tree/main/reports/needed).

## Use the application

Follow the [atlas walkthrough](../interfaces/atlas-walkthrough.md) to inspect
one published modeled-context cell, trace its source and reproduce its
bounded country/window summary. The route separates map behavior from
scientific acceptance.

For installation and command usage, follow [installation and setup](../operations/installation-and-setup.md)
and the [supported interfaces](../interfaces/index.md). Read the input
prerequisites before selecting an exploratory reconstruction; a working map
or command does not supply missing scientific inputs.
