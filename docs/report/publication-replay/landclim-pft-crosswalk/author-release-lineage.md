# Boundary of the released LandClim II calculation script

The public [LandClim II source repository at commit
`57ead2e2fcc493d099be4e5a3092fc396e1c3d3a`](https://github.com/rmfyfe/landclimII/tree/57ead2e2fcc493d099be4e5a3092fc396e1c3d3a)
contains 51 files, including three R scripts. The separately retained author
source capsule authenticates the same [REVEALS wrapper](https://github.com/rmfyfe/landclimII/blob/57ead2e2fcc493d099be4e5a3092fc396e1c3d3a/Kunes_REVEALS_iterate_across_sitelists.R)
and [taxon header](https://github.com/rmfyfe/landclimII/blob/57ead2e2fcc493d099be4e5a3092fc396e1c3d3a/run.REVEALS.files/taxa.csv):

| `run.REVEALS.files/taxa.csv` | `95b081a39666e46d1bcc375d2fa1dd495f7e1081` | `6aac6ac4615d203383fb3c73eac7581db592984ba08dd2ddf7e08c52165dd237` |

The wrapper loads `taxa.csv` as its output header, writes grid-by-window
`Mean_V` and `Mean_SE` estimates from the released REVEALS function, and
describes those files as taxon outputs. Its `taxa.csv` has `gridcell` plus
**31 taxon names**. Those 31 names exactly equal positions 4–34 of the
first pinned [PANGAEA 937075](https://doi.org/10.1594/PANGAEA.937075)
mean-file header, after its `LCGRID_ID`, `lonDD`, and `latDD` columns. The
archive then has **16 more columns**: 13 PFT codes, including `ISTS`, and
three LCT codes. Neither the three R scripts nor the repository README
defines a transformation that writes those 16 columns. This establishes a
taxon-output lineage lead, not identical historical numeric inputs or proof
that the archived taxon values were generated by this exact commit.

The PFT/LCT classification and uncertainty aggregation therefore occur in a
stage whose source code and version have not been authenticated here. In
particular, the released taxon calculation cannot resolve why the [paper](https://essd.copernicus.org/articles/14/1581/2022/)
assigns deciduous Quercus type to TBS while the archived mean arithmetic
places `Quercus.deciduous` in `ISTS`. The source owner would need to identify
the archive-producing PFT/LCT transformation and its input version before
the biological classification, 11/12/13 PFT count and SE covariance can be
certified. The archived numeric columns remain unaltered.
