## Scientific verification and limits

Published-product versus released-author-example correspondence, not authenticated original input reconstruction.

**Supported claim.** This pointer locates the exact released-author method profile and retains machine crosswalk/input ledgers tying executable, parameters, units and prepared examples to that named calculation.

**Unsupported claim.** A method profile is not physical applicability to a new Nordic core, a bog-specific validation, observed missing-taxon zero, full historical reconstruction, rights clearance or vegetation accuracy.

**Actual verification performed.** The pointer, source-profile report and method/input ledgers were inspected and bound. The linked maintained reader historically reproduced crosswalk/ledger bytes and corrected one custody reference; it consumes retained receipts rather than executing R/native models. This qualification performs no profile replay or new numerical study.

**Remaining input or review.** The historical lake gamma comment, source NA-to-zero handling, source/profile lineage, PFT discrepancy, core-specific chronology/geometry/PPE and private-source rights need explicit interpretation and qualified review.

**Cause category.** Citation routing | data | assumption | comparability | qualified review

**Consequence.** Keep source percent versus native fractions and missing site/bin masks explicit. A source lake input or 1,000-draw bootstrap does not validate real basin geometry or represent all omitted PPE/chronology uncertainty.

**Precise next acceptance route.** Authenticate the intended core/window source choices and parameter/measurement/rights decisions, then run the named profile on that admitted scope. Preserve the source lake gamma and missing-support differences rather than silently transferring them.

**Negative or refused result.** All 17 examples have model code 2(lake); no bog profile is validated. Source zero replacement is not observed absence, source multisite bootstrap omits PPE covariance, and the 12/11/13 functional-type disagreement remains unresolved.

**Matched denominator.** Own pointer adds zero fits. Linked profile 193 source members,17 lake rows (nine+eight),31 PPE/fall-speed/covariance axes,26 boundaries/25 bins and 1,000 source site-resampling draws; parameter/source identity is separate from empirical suitability.
