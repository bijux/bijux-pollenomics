# LandClim published-window provenance

We maintain the scientific decision, modeled-product differences and limits in
our [root research report](https://github.com/bijux/bijux-pollenomics/blob/main/reports/science/publication-correspondence/published-window-provenance.md).
The [124-row ledger](paper-correspondence.csv), [machine summary](report.json),
[generated calculation detail](REPORT.md) and [source manifest](manifest.json)
remain at this governed producer path. This page preserves earlier website
citations.

The producer writes LF CSV to match the governed ledger exactly. Its three
outputs can be compared byte for byte after the bounded reproduction command
in the root research report. The comparison covers 124 paired numerical values
for one author bin in two grids; it does not establish historical raw-input
identity or measured vegetation accuracy.
