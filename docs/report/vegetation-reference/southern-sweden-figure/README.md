# Published southern Swedish vegetation comparison

Read our [vegetation-reference decision](https://github.com/bijux/bijux-pollenomics/blob/main/reports/science/vegetation-reference.md),
the [nine-label calculation](https://github.com/bijux/bijux-pollenomics/blob/main/reports/science/vegetation-reference/southern-sweden-figure/report.json),
its [transcribed values](https://github.com/bijux/bijux-pollenomics/blob/main/reports/science/vegetation-reference/southern-sweden-figure/printed-labels.csv)
and the [producer](https://github.com/bijux/bijux-pollenomics/blob/main/reports/science/vegetation-reference/southern-sweden-figure/compare.py).

[Gaillard et al. (2010), Figure 6](https://cp.copernicus.org/articles/6/483/2010/)
prints rounded pollen, REVEALS and observed-vegetation values for a selected
set of taxa. On the nine region/taxon labels printed in all three panels,
published REVEALS mean absolute error is 5.11 percentage points versus
17.33 for published raw pollen. The comparison does not score any prediction
from this repository or recover the original 26-taxon study.
