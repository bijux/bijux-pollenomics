# Published southern Swedish vegetation comparison

Our research decision is in `reports/science/vegetation-reference.md`. The
source-bound nine-label transcription, calculation and producer are now owned
together at `reports/science/vegetation-reference/southern-sweden-figure/`.

[Gaillard et al. (2010), Figure 6](https://cp.copernicus.org/articles/6/483/2010/)
prints rounded pollen, REVEALS and observed-vegetation values for a selected
set of taxa. On the nine region/taxon labels printed in all three panels,
published REVEALS mean absolute error is 5.11 percentage points versus
17.33 for published raw pollen. The comparison does not score any prediction
from this repository or recover the original 26-taxon study.
