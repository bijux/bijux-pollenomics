## Distance sensitivity of nearby source features

We compared the retained spherical distance with WGS84 for all 8,799 source features at the BUS and BOKE points and the declared alternative BUS point. The [aggregate report](geodesic-sensitivity.json) and [window ledger](geodesic-window-cells.csv) preserve all 156 method/window cells. Of these features,7,244 have numeric date support and 1,555 remain unresolved.

Twenty-nine spatial memberships change. Only the BOKE 20 km windows 0–500 and 500–1,000 BP change their dated context: each loses 14 features from one site, with 18 and 16 fewer distinct source claims respectively. The minimum WGS84 boundary margin is 4.755 metres; no feature is within 1 mm. This changes source proximity support; it does not establish archaeological event age, vegetation or causal land use.

The [source account](geodesic-source.json) preserves native execution, all 78 reproduced original spherical cells, reference controls and failed preparations. WGS84 checks share the PROJ backend; they are not a second ellipsoid implementation. Source chronology, uncertainty qualifiers and the shared LandClim grid remain unchanged.

## Scientific verification and limits

Swedish observed pollen/modeled land use/archaeological context has separate provenance and no causal or ecological validation.

**Supported claim.** The retained two-lake trajectory is supplemented by an actual source-bound spherical/WGS84 context-membership sensitivity: 8,799 features, three prespecified coordinates and 156 method/window cells. Twenty-nine spatial memberships differ; only two dated BOKE 20 km bins change.

**Unsupported claim.** The pointer and descriptive two-lake agreement cannot validate land use or vegetation: LandClim shares these input sites and SEAD lacks a qualified comparable ecological measurement.

**Actual verification performed.** Actual 26,397 feature–centre distance comparisons reproduced all 78 original sphere cells. Independent source/ID/bin/count reconstruction and scalar distance checks passed; 57 published distance/boundary controls retained. Two public aggregate products exactly reproduce qualified private outputs; no source chronology or pollen model was refitted.

**Remaining input or review.** Qualified independent ecological measurements and source-compatible chronology are required before interpreting concordance as a land-use trajectory.

**Cause category.** Citation routing to descriptive observed-pollen trajectories with dependent modeled context.

**Consequence.** Apparent agreement or contradiction remains source-local description; no independent land-use/vegetation conclusion follows.

**Precise next acceptance route.** Inspect the geodesic report/window ledger and original trajectory separately; qualify source-compatible event chronology, historical basin/core support, independent measurements and rights before any land-use/vegetation interpretation.

**Negative or refused result.** WGS84 removes 14 features from one BOKE 20 km site in each 0–500 and 500–1,000 BP bin; claim deltas are −18 and −16. The 1,555 undated features remain unresolved. No best coordinate, archaeological event or causal land-use conclusion is selected.

**Matched denominator.** Original two lakes × two taxa / 13 bins / 48 threshold contrasts remain historical. Separate geography scenario:8,799 features = 7,244 numeric + 1,555 unresolved; three centres × two radii × 13 bins × two distance methods = 156 cells; repeated windows/features/sites are not independent observations.
