# Sweden lake archaeology-weight sensitivity

This report isolates how much the lake shortlist changes when archaeology is
treated conservatively, at the published baseline, or with added contextual
emphasis. It does not turn nearby archaeology into proof of lake suitability.

## Why The Baseline Is 0.07

The 0.07 archaeology weight is a declared design profile; no eligible lake candidates were available to evaluate it.

The archaeology component is itself bounded: RAÄ density remains display-only because source authority is refused. The available SEAD components are renormalized to site density 0.50, numeric chronology 0.25, and chronology overlapping nearby human aDNA 0.25. No missing RAÄ value is scored as zero.
When archaeology weight changes, every non-archaeology component is scaled proportionally so profile weights continue to sum to 1.00.

## Decision Rule

RAÄ density is display-only while source authority is refused; it cannot promote a lake or support candidate ranking.

Each sensitivity row publishes the candidate's available temporal context windows and the count of nearby numeric SEAD records. A weight change remains a static robustness check; interpretation in a particular period requires a matching SEAD context window.

Sensitivity rank is score-ordered for isolating weight effects; the published engine rank separately applies direct-evidence tie-breakers.

The maximum absolute movement across the tested profiles is
**not evaluated**: no eligible lake candidates were available.
