# Nested transport development comparison

This retrospective development analysis compares five transport settings within the frozen author LOVE profile. Each of fifteen outer site folds chooses a transport separately for each spatial baseline using its fourteen inner sites. All fifteen sites were previously exposed development evidence and legitimately train other folds. The result supplies conditional pollen prediction diagnostics; it does not establish untouched test performance or independent vegetation accuracy.

The stored ledgers contain 10,752 new starts and 1,728 reused starts. New starts: 10,209 accepted and 543 refused. Unique attempt count is 12,480; repeated logical references are not additional fits.

The separate no-fit saved-product observer and new evaluation have their own successful native identities. The original final function return and complete later module-origin inventory remain unqualified. Neither recovery nor publication rewrites those original statuses.

All 3,375 candidate prediction/refusal slots are frozen before new inner scoring. The 45 selected outer slots are then frozen before new outer scoring. Each fold excludes its own target and outer group during selection; these source order constraints do not imply that source labels were globally unread.
