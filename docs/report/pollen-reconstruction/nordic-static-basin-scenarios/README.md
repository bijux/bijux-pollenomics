## Physical response and estimator

Sources within the receiving basin are excluded under this scenario.

For each taxon the conditional estimator is `v_i = [n_i / (K_i PPE_i)] / sum_j[n_j / (K_j PPE_j)]`, where `K_i` is the maintained annulus response.
