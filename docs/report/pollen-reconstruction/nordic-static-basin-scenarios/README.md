## Physical response and estimator

The regional source annulus extends from the assumed receiving-disk radius to 100 km. A homogeneous isotropic source GPM displacement law is averaged uniformly across that disk. Wind speed is assumed to be 3 m/s, turbulence exponent parameter 0.25 and the source empirical metre-based diffusion coefficient 0.12. The diffusion coefficient is not an SI diffusivity in m²/s. Sources within the receiving basin are excluded under this scenario.

For each taxon the conditional estimator is `v_i = [n_i / (K_i PPE_i)] / sum_j[n_j / (K_j PPE_j)]`, where `K_i` is the maintained annulus response. Counting covariance uses the selected panel count N. PPE uncertainty assumes a diagonal covariance of the source SD squared. Full taxon covariance, its counting/PPE decomposition and marginal SE are retained for each window. The same PPE values are shared across windows and geometry cases; marginal SEs are not independent draws. No joint cross-window or cross-core covariance block is calculated. A boundary plug-in SE of zero would not establish true absence or an absence uncertainty interval.

The receiving radii are explicit constant-geometry alternatives: Laihalampi 285 m and the equivalent circle for 25.5 ha; Dalmutladdo 160 m and circles for 7.2/8.0 ha; both Solsø cores 89 m and the circle for 2.5 ha. Areas convert by `r = sqrt(10,000 A / pi)`, with A in hectares. Source drained-lake/hiatus and core correspondence remain relevant limitations. None of these radii establishes dated shorelines or physical basin accuracy.

Maximum metadata-baseline transport-plus-PPE correction relative to direct panel pollen is 1.344 percentage points at Laihalampi, 32.428 at Dalmutladdo, 45.477 at Solsø81 and 37.531 at Solsø83. These are changes in each distinct conditional panel, not measured accuracy. The largest alternative-area radius effect is 0.059 percentage points at Dalmutladdo under the fixed scenario; small numerical sensitivity does not validate the geometry. [The saved-output summary](diagnostics/summary.json) retains exact windows, axes and signed extrema.
