# Swedish pollen composition under declared parameter-transfer hypotheses

Four native Swedish pollen records support a wider conditional reconstruction than the separately retained [literal-panel account](../swedish-static-basin-scenarios/README.md). This account treats generic labels, dwarf birch and grass-size classes as explicit parameter-transfer alternatives. It preserves their consequences rather than treating a genus label as an authenticated species identification. These are modeled compositions conditional on the mapped pollen panel, not measurements of vegetation area or a replay of the historical 1,128-record LandClim preparation.

The original source population is 273 samples. Each wider alternative retains **267 samples in 79 occupied core/windows**, using 278,368 reported pollen NISP grains. Six source ages lie outside the declared nonnegative calendar-BP windows. BUS retains six more samples and two more windows than the original strict Betula/Ulmus panel because the wider scenario explicitly hypothesizes zeros for unreported selected source labels. Those hypotheses do not create observed rows.

The percentages divide mapped counts by all reported pollen counts in included samples. They are count-mass coverage, not vegetation coverage. Residual pollen remains explicit and is not reconstructed by these parameter vectors. Even high count coverage cannot establish that a residual pollen type has negligible vegetation cover.

The [assumptions](assumptions/parameter-transfer.json) define four alternatives: literal public parameter strings; declared major label-to-parameter transfers; an additional Betula nana transfer onto the same Betula PPE; and an additional large-grass transfer onto Cerealia-type PPE. Examples of major transfers include generic Pinus onto Pinus sylvestris PPE and Poaceae undifferentiated below 40 micrometres onto Poaceae PPE. These are surrogate parameter choices. Betula nana is not counted as forest by accepting a shared PPE, and large grass is not identified as cultivated cereal. Humulus/Cannabis, Phragmites and other unsupported labels remain residual where appropriate.

The sparse-input assumption is equally explicit: selected source labels absent from a sample are hypothesized to contribute zero. Actual source-label presence is retained before any many-to-one merge, so a present birch label cannot hide an absent sibling contribution. The major scenario imposes 969, 310, 410 and 139 source-label zero cells in ABB, BOKE, BUS and Tibetanus, respectively. Actual reported zero rows and imposed zeros remain separate. Each source count is allocated once; mapped counts plus residual must equal all reported pollen NISP. A finite parent/child coexistence guard refuses ambiguous selected pairs. The full native higher-taxon and synonym graph has not been authenticated; that lexical guard is not proof of complete taxonomic independence.

Numerical sensitivity to the additional assumptions is substantial in individual windows. Sharing dwarf-birch PPE changes Tibetanus's conditional Betula fraction by as much as **13.7963 percentage points**, in the 10,200–10,700 cal BP window. The BUS large-grass cereal proxy changes its conditional Poaceae fraction by as much as **3.06615 points**, in the 0–100 cal BP window. These adjacent comparisons retain both target axes and count denominators. They describe model alternatives, not measured ecological change.

The physical response, inverse closure and conditional counting/PPE covariance follow the [explicit mathematical account](../swedish-static-basin-scenarios/README.md). Radii are transferred as static metadata assumptions; Tibetanus retains the provisional basin linkage and elevation discrepancy in the [source reconciliation](../swedish-static-basin-scenarios/assumptions/source-reconciliation.json). BP is tied to AD 1950 in the selected calibrated native chronologies. All 267 retained point ages lack raw age bounds. The new youngest interval starts at 0 BP; the historical paper's youngest interval starts at the actual core-surface date. Chronology, mapping, sparse reporting, basin geometry and model discrepancy are not propagated into the conditional delta SEs. Zero plug-in SE at observed or imposed zero does not prove absence or interval coverage.
