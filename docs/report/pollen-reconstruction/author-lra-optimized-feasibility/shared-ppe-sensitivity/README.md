# English shared-PPE likelihood sensitivity

The [compact report](report.json) and [per-draw diagnostics](diagnostics.json)
describe one prior-exposed English training pair. The source-bound request uses
30 author-prepared taxa after excluding Filipendula, fixed regional and local
pollen count totals of 699 and 553, and the retained peatland geometry. The
first row uses the nominal author PPE means. Each of 63 later rows draws one
positive PPE vector from the source-declared diagonal covariance, then uses
that same vector for regional cover and the local/background coefficients.
The second local ring has zero kernel weight under this source-compatible
geometry, so the two exposed local prefixes are identical.

The report names each taxon and separates nominal local cover from the mean,
sample standard deviation, and fifth and ninety-fifth percentiles of the
63 stochastic rows. These are conditional numerical sensitivity summaries,
not confidence intervals for historical vegetation or field PPE uncertainty.
The recorded likelihood gaps and forward checks establish numerical completion
for this exposed training pair only. They do not establish held-out prediction,
ecological accuracy, physical basin interpretation, or source-rights admission.

The original author snapshot and privately prepared request remain outside
the report tree. Rebuilding this account requires an explicit qualified source
root; it publishes only the compact derived report and scalar diagnostics.
