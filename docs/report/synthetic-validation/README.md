# Synthetic method challenges

We use these five fabricated, prospectively declared cases to test numerical
and workflow behavior. Their producers reproduce all five governed `report.json`
files byte for byte from the stated fixtures. Each linked report names its
producer, input contract, expected outcome and limits:

| Question | Governed result |
| --- | --- |
| First observed change time and observation schedule | [Change time](change-time/README.md) |
| Derived event propagation and boundary choices | [Propagation](propagation/README.md) |
| REVEALS recovery under known landscapes and changed parameters | [Reconstruction](reconstruction/README.md) |
| Physical-site aliases and target ancestry leakage | [Site leakage](site-leakage/README.md) |
| Spatial and age interval eligibility at fixed thresholds | [Spatial eligibility](spatial-eligibility/README.md) |

These cases verify the declared synthetic behaviors. They do not estimate
Nordic vegetation accuracy, provide source-qualified LRA inputs or establish
historical event routes.
