# Earlier Swedish LRA source request

The [original unsent request](source-request.md) preserves the exact working
document from the author-example pollen holdout run. It is historical process
evidence, not a current admission decision or a request that was sent to a
source owner. Its Klotjärnen lead and Abborrtjärnen, Bussjösjön and Bökesjön
questions explain why the earlier run did not use Swedish pollen as LRA input.

The [current Swedish source questions](../../../pollen-reconstruction/swedish-source-questions.csv)
and [scientific account](../../../pollen-reconstruction/README.md) supersede its
status statements. Later source work bound the 31-target author parameter
profile and several core/count and age correspondences; historical basin
geometry and a complete count-denominator decision still prevent Swedish LRA
admission. Artifact paths inside the original request are historical locators,
not live dependencies. The [retirement receipt](../author-pollen-holdout-retirement.json)
binds its original and retained bytes.
