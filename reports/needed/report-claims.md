# Unresolved causes in scientific reports

The [index](report-claims.csv) covers **61 primary scientific accounts**: all 56 Markdown reports under `reports/science/` and five explicitly listed public aggregate readers in [the account authority](claim-account-sources.json). Citation wrappers remain covered by their existing research accounts. It excludes generated JSON, CSV and PDF products. Each report has one row with its supported scoped claim, unsupported extension, retained verification, negative or refused result, matched denominator, practical consequence, cause categories, evidence paths, resolver role and precise next acceptance route. The report path is the coverage key; the categories are not mutually exclusive.

`actual_verification_performed` describes checks documented in the source report or its retained receipt. Building this index did **not** rerun a source acquisition, model, calculation, permission review or independent scientific reading. `negative_or_refused_result` states a real refusal, observed discrepancy or explicitly unevaluated result; “not evaluated” never means zero accuracy. `matched_denominator` names the actual sites, samples, bins, taxa or cells behind the scoped result so unlike axes cannot be pooled. `source_report_sha256` pins the Markdown account that each row describes. `packet_reference` uses IDs from [the existing unsent source-request register](source-requests.csv) when its question applies, and `none` otherwise; an ID does not mean the packet was sent or accepted.

The entries preserve the difference between a completed calculation and an unqualified scientific extension. For example, `reports/science/publication-correspondence/published-inventory/README.md` closes the published archive's row inventory, while `reports/science/publication-correspondence.md` still needs historical pollen inputs and the archive-producing PFT/uncertainty transformation. The completed Sämbosjön sensitivity scores 21 of 22 nominal bins from 53 interval-contained samples with unchanged frozen predictions; it does not yield a joint-age posterior or vegetation accuracy. The analytical LOVE ring fixture has 30 finite output cells on unmasked rings, but negative and greater-than-one values prevent reading them as valid cover. The two `none within stated scope` rows are the paper-account inventory and published estimate inventory; that label never promotes them into historical reconstruction or ecological validation.

The recurring source chain is specific. A LandClim historical replay needs the selected sequence rows, age/window choices, basin and parameter profile, and producing PFT/covariance code. A Nordic LRA case needs those fields for the **same physical core and window**, plus permitted analytical use. A vegetation score then needs an independent measured reference aligned by site, time, taxa, area and unit. A fresh prediction claim additionally needs an eligible cohort frozen before target outcomes are opened. The index keeps these causes separate so a numerical parity result is not mistaken for input closure or ecological accuracy.

The exact coverage set combines all research Markdown accounts with the supplemental primary readers declared in `claim-account-sources.json`. The CSV has **61 unique `report_path` values**, exactly equal to that owned inventory. Every local path in its evidence and consumer columns exists; each source-report hash matches the current Markdown bytes and every non-`none` packet ID exists in the register. [The index verifier](verify-claims.py) repeats the inventory, category, path, packet and hash checks without rerunning source studies; its descriptions are an editorial reading of the retained reports, not a new source audit, source permission, colleague reading or independent scientific endorsement.

## On-page verification and source-bound reading routes

All 61 primary scientific accounts now expose nine verification fields directly under “Scientific verification and limits.” The maintained renderer preserves their authored prose and binds the claim semantics separately from the full report hash. A source change, partial block or altered denominator refuses validation.
