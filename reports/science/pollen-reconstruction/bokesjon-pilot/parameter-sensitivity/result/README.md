# Conditional BOKE/KRAG nominal PPE comparison

This is a two-tree composition of Betula and Ulmus under the retained pooled count, chronology, basin and regional-background assumptions. It is neither full forest/open/cereal cover nor measured vegetation accuracy.

The comparison changes shared Betula PPE from 5.106 to 4.94 in both stages. Ulmus remains 1.27 because the selected European reference is missing. Fall speeds and source SD metadata are unchanged. No source SD law is propagated and the unweighted design supplies no mean, covariance, probability interval or empirical confidence interval.

Changes below are comparison minus baseline in percentage points. Each local result is clipped and renormalized before comparison; raw signed values remain visible. A zero adjusted change can hide a raw change.

The clipping policy follows the discussion with supervisor Anneli Poska reported by the project author (personal communication; discussion date not recorded). Negatives become zero and surviving positive mass is renormalized. A realization with no positive mass fails explicitly.
