## Reuse selected recorded metadata

resolvers. This route opens no native response body and grants no GET, current
source-role or scientific authority. The adjacent captured detail bodies are
separate source evidence; reading their names is a different operation.

```python
from pathlib import Path
from bijux_pollenomics.collection.sources.neotoma.capture.linked_resources.ancestry.chain import (
    read_neotoma_taxon_chain_target,
)

root = Path("data/neotoma/ancillary-resources/taxon-ancestry").absolute()
baseline = "84a831c05c7d018392293747925a4229faf4be935a1552ef6bdbf4587d1d0662"
chain = "0e7e37196a8eabc771b336bec25f981bfc6a291148dc519b9ce6c4f8212e2064"

recorded = read_neotoma_taxon_chain_target(
    root / "chains" / chain,
    expected_manifest_sha256=chain,
    kind="taxon",
    native_id=327,
    chain_sources={baseline: root / baseline},
)
```
