# Map software notices

The unchanged portable map uses Leaflet 1.9.4 and Leaflet.markercluster 1.5.3.
All ten vendored JavaScript, CSS and image files were matched byte-for-byte to
the corresponding versioned upstream npm distributions. The original Leaflet
copyright header remains in the map. Exact upstream notices are retained here,
outside the immutable 24-file `atlas/` tree:

- [Leaflet BSD 2-Clause notice](leaflet/LICENSE), from
  [Leaflet v1.9.4](https://github.com/Leaflet/Leaflet/blob/v1.9.4/LICENSE).
- [Leaflet.markercluster MIT notice](markercluster/MIT-LICENCE.txt), from
  [Leaflet.markercluster v1.5.3](https://github.com/Leaflet/Leaflet.markercluster/blob/v1.5.3/MIT-LICENCE.txt).

These software notices are separate from the RAÄ dataset's retained rights
statement in the account and context metadata. Retain this notices directory
when redistributing the portable map.
