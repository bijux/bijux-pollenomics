# Galician cattle source review captures

This directory owns the retained PLOS article, its author-name correction,
two supplementary tables, and eleven ENA BioSample XML records for the
PRJNA705960 paper review. The files are byte-identical to the reviewed
captures; the [paper review](../../../../docs/report/source-relations/dna-scope/galician-cattle-paper.json)
records each file's source URL, byte count, and SHA-256 digest. The governed
ENA project archive remains under `data/adna/governance/source_library/`.

These captures support the paper-to-BioSample identity crosswalk. They do not
resolve sample locality or chronology, promote the project paper link, or
admit a Nordic atlas point.
